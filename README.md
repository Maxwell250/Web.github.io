# ВКСервис Норильск — сайт компании

Полноценный одностраничный сайт для компании **ООО «ВКСервис»** (г. Норильск):
технические газы, криогенные жидкости и строительно-монтажные работы.

Источник данных о компании: [карточка в 2ГИС](https://2gis.ru/norilsk/firm/70000001090834312).

## Что внутри

- **Hero-секция** с УТП и формой быстрого расчёта заявки.
- **Блок статистики** с анимированными счётчиками.
- **Продукция** — технические газы и жидкий азот с ценами.
- **Услуги** — кровельные, бетонные, сварочные работы, баки ТКО, ворота и др.
- **Прайс-лист** — таблицы с актуальными ценами.
- **Преимущества**, **отзывы**, **CTA-баннер**.
- **Контакты** с формой обратной связи и реквизитами.
- Адаптивная вёрстка (десктоп / планшет / мобильный), мобильное меню.
- SEO: мета-теги, Open Graph, микроразметка `LocalBusiness` (Schema.org).
- Доступность: семантические теги, `aria`-атрибуты, поддержка `prefers-reduced-motion`.

## Технологии

Чистые **HTML + CSS + JavaScript**, без сборщиков и зависимостей.
Шрифт [Manrope](https://fonts.google.com/specimen/Manrope) подключается через Google Fonts.

## Структура

```
.
├── index.html              # разметка страницы
├── assets/
│   ├── css/style.css       # стили
│   ├── js/main.js          # меню, формы, анимации, маска телефона
│   └── img/                # логотип и favicon (SVG)
└── README.md
```

## Запуск локально

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```
